# 教材使用规则

本目录处理李庆扬、王能超、易大义《数值分析》第 5 版。先读 `README.md`、`STATUS.json` 和 `index/sections.json`。

正文入口为 `textbook.md` 或 `verified/sections/<编号>.md`，按原页回查用 `verified/pages/pdf-NNN.md`。章节文件从逐页核验稿派生；章、节、子节可能覆盖相同内容，不能重复计数。JSON 中的文件路径，以及逐页 YAML 的 `source_image`、`primary_transcription`，以本目录为基准；Markdown 链接和显式 `../` 路径以所在文件为基准。

- 原 PDF 是最终文字、数学符号、编号、图表与题目依据。不得修改原 PDF。
- `ocr/` 是机器识别候选，未经逐页核验，不能直接当作教材的正确公式或引用来源。模型置信度、LaTeX 编译成功、两次 OCR 一致均不等于内容正确。
- `verified/` 只收录已对照原页逐字逐式核验的内容。核验记录在 `quality/`；核验是 agent 核验，不得称为人工核验或数学上绝对无误。
- 使用章节时核对编号、标题、书页码、PDF 页码。此版本 **2.2.1 是插值多项式的存在唯一性；2.2.2 是线性插值与抛物插值**。用户同时给出的编号与主题若冲突，应先说明冲突；不能改写教材编号迎合指令。
- 保留公式编号、上下标、大小写、正负号、求和与乘积上下限、导数阶数、矩阵尺寸以及定理假设。字母 `l`、数字 `1` 与 `I`，`x` 与乘号，`v` 与 `ν` 等须回原图核对。
- 教材转录、教材图的几何重绘、agent 补充解释、另选数值例子分开标注。原图没有具体数值或函数时，不得把自行选择的参数说成教材数据。
- 发现疑似原书错误时保留原文，单列疑误说明与推导，不能静默改正。
- 章节尚未核验时先定位原页并完成所需段落的核验，再计算或绘图。不要仅因为关键词检索命中就使用 OCR 公式。
- 全书完成必须同时满足：扫描页完整覆盖，全部应转录内容已整理，所有正文/公式/图表/习题已逐页核验，未决问题为零，Markdown 与 LaTeX 内容一致，检索与代表性绘图验收通过。当前完成情况以 `STATUS.json` 为准。
