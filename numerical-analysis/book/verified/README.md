# 核对后的逐页与章节文件

全书入口为 [textbook.md](../textbook.md)、[textbook.tex](../textbook.tex) 和 [textbook.pdf](../textbook.pdf)，使用说明见 [教材 README](../README.md)。

- [sections/](sections/)：按 275 个章节条目整理的同编号 `.md` 与 `.tex` 文件；从 [章节索引](../index/INDEX.md) 选择所需条目。
- [pages/](pages/)：按原 PDF 页码保留的逐页转录。
- [assets/](assets/)：正文引用的原图与证据图。

正文保留原书印字，疑误、条件和记号解释在相邻 agent 校注中。核对由 agent 完成；来源与检查记录见 [quality/](../quality/)。

旧的六组长文件名 Markdown/LaTeX 及本目录原 `textbook.tex` 已移入 [先导版追溯目录](../.work/legacy-pilot/README.md)。请使用新的 `sections/<编号>.md`、`sections/<编号>.tex` 和书库根目录的全书入口。
