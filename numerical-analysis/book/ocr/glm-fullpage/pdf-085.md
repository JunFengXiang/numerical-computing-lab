$$\begin{cases} a_k = \frac{1}{\pi} \int_0^{2\pi} f(x) \cos kx \mathrm{d}x & (k = 0, 1, \dots, n), \\ b_k = \frac{1}{\pi} \int_0^{2\pi} f(x) \sin kx \mathrm{d}x & (k = 1, 2, \dots, n), \end{cases}$$

$a_k, b_k$ 称为 Fourier 系数，函数 $f(x)$ 按 Fourier 系数展开得到的级数

$$\frac{1}{2} a_0 + \sum_{k=1}^{\infty} \left( a_k \cos kx + b_k \sin kx \right)$$

就称为 Fourier 级数，只要 $f'(x)$ 在 $[0, 2\pi]$ 上分段连续，则级数 (3.7.3) 一致收敛到 $f(x)$.

当 $f(x)$ 只在给定的离散点集 $\left\{ x_j = \frac{2\pi}{N} j, j = 0, 1, \dots, N-1 \right\}$ 上已知时，则可类似得到在离散点集上的正交性与相应的离散 Fourier 系数. 为方便起见，下面只给出奇数个点的情形. 令

$$x_j = \frac{2\pi j}{2m+1} \quad (j = 0, 1, \dots, 2m),$$

可以证明，对于任何 $0 \leqslant k, l \leqslant m$，成立

$$\begin{cases} \sum_{j=0}^{2m} \sin lx_j \sin kx_j = \left\{ \begin{array}{ll} 0, & l \neq k, l = k = 0, \\ \frac{2m+1}{2}, & l = k \neq 0, \end{array} \right. \\ \sum_{j=0}^{2m} \cos lx_j \cos kx_j = \left\{ \begin{array}{ll} 0, & l \neq k, \\ \frac{2m+1}{2}, & l = k \neq 0, \\ 2m+1, & l = k = 0, \end{array} \right. \\ \sum_{j=0}^{2m} \cos lx_j \sin kx_j = 0, & 0 \leqslant k, j \leqslant m. \end{cases}$$

这就表明，函数族 $\{1, \cos x, \sin x, \dots, \cos mx, \sin mx\}$ 在点集 $\left\{ x_j = \frac{2\pi j}{2m+1} \right\}$ 上正交. 若令 $f_j = f(x_j)$ ($j = 0, 1, \dots, 2m$)，则 $f(x)$ 的最小二乘三角逼近为

$$S_n(x) = \frac{1}{2} a_0 + \sum_{k=1}^{n} \left( a_k \cos kx + b_k \sin kx \right), \quad n < m,$$

其中

$$\begin{cases} a_k = \frac{2}{2m+1} \sum_{j=0}^{2m} f_j \cos \frac{2\pi jk}{2m+1} & (k = 0, 1, \dots, n), \\ b_k = \frac{2}{2m+1} \sum_{j=0}^{2m} f_j \sin \frac{2\pi jk}{2m+1} & (k = 1, \dots, n). \end{cases}$$

当 $n = m$ 时，可证明 $S_m(x_j) = f_j$ ($j = 0, 1, \dots, 2m$)，于是

$$S_m(x) = \frac{1}{2} a_0 + \sum_{k=1}^{m} \left( a_k \cos kx + b_k \sin kx \right)$$
