2.4 差商与 Newton 插值公式

2.4.1 差商及其性质

Lagrange 插值公式可以看作直线方程两点式的推广, 如果从点斜式直线方程

$$P_1(x) = f_0 + \frac{f_1 - f_0}{x_1 - x_0}(x - x_0)$$

出发, 将它推广到具有 $n+1$ 个插值点 $(x_0, f_0), (x_1, f_1), \dots, (x_n, f_n)$ 的情况, 则可把插值多项式表示为

$$P_n(x) = a_0 + a_1(x - x_0) + a_2(x - x_0)(x - x_1) + \dots + a_n(x - x_0)\cdots(x - x_{n-1}),$$

(2.4.1)

其中 $a_0, a_1, \dots, a_n$ 为待定系数, 可由插值条件 $P_n(x_j) = f_j(j=0,1,\dots,n)$ 确定.

当 $x = x_0$ 时, $P_n(x_0) = a_0 = f_0$; 当 $x = x_1$ 时, $P_n(x_1) = a_0 + a_1(x - x_0) = f_1$, 推得

$$a_1 = \frac{f_1 - f_0}{x_1 - x_0};$$

当 $x = x_2$ 时, $P_n(x_2) = a_0 + a_1(x_2 - x_0) + a_2(x_2 - x_0)(x_2 - x_1) = f_2,$

推得

$$a_2 = \frac{f_2 - f_0}{x_2 - x_0} - \frac{f_1 - f_0}{x_1 - x_0}$$

依此递推, 可得到 $a_3, a_4, \dots, a_n$. 为写出系数 $a_k$ 的一般表达式, 先引进如下差商定义.
