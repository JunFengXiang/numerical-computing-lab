2.8.5 三次样条插值的收敛性

为了证明三次样条插值的收敛性，需要用到向量与矩阵范数及有关结论，可参看 7.5 节.

设 $A = (a_{ij})_n$ 为 $n \times n$ 矩阵，$x = (x_1, x_2, \cdots, x_n)^T$ 为 $n$ 维向量，定义 $x$ 及 $A$ 的范数为

$$\|x\|_\infty = \max_{l \leq i \leq n} |x_j|,$$

$$\|A\|_\infty = \sup_{x \neq 0} \frac{\|Ax\|_\infty}{\|x\|_\infty}.$$

(2.8.21)

同样，对于函数 $f(x) \in C[a,b]$，也定义 $f$ 的范数为

$$\|f\|_\infty = \sup_{a \leq x \leq b} |f(x)| = \max_{a \leq x \leq b} |f(x)|.$$

引理 若 $A = (a_{ij})_n$ 具有强对角占优，即

$$\sum_{j \neq i} |a_{ij}| < |a_{ii}| \quad (i = 1,2,\cdots,n),$$

(2.8.22)

则 $A^{-1}$ 存在，且

$$\|A^{-1}\|_\infty \leq \left\{\min(|a_{ij}| - \sum_{j \neq i} |a_{ij}|)\right\}^{-1}.$$

(2.8.23)

该引理的证明可参考定理 8.6 和第 8 章习题 20.
