4.2.3 几种低阶求积公式的余项

首先考察梯形公式, 按余项公式(4.1.7), 梯形公式(4.1.1)的余项为
$$R_T = I - T = \int_a^b \frac{f''(\xi)}{2} (x - a)(x - b) \mathrm{d}x.$$
这里积分的核函数 $(x - a)(x - b)$ 在区间 $[a,b]$ 上保号 (非正), 应用积分中值定理, 在 $(a,b)$ 内存在一点 $\eta$, 使
$$R_T = \frac{f''(\eta)}{2} \int_a^b (x - a)(x - b) \mathrm{d}x = -\frac{f''(\eta)}{12} (b - a)^3, \quad \eta \in (a,b).$$
再研究 Simpson 公式(4.2.3)的余项 $R_S = I - S$. 为此构造次数不大于三的多项式 $H(x)$, 使之满足
$$H(a) = f(a), \quad H(b) = f(b), \quad H(c) = f(c), \quad H'(c) = f'(c),$$
(4.2.6)
这里 $c = \frac{a + b}{2}$. 由于 Simpson 公式具有三次代数精度, 它对于这样构造出的三次式 $H(x)$ 是准确的:
$$\int_a^b H(x) \mathrm{d}x = \frac{b - a}{6} \left[ H(a) + 4 H(c) + H(b) \right].$$
而由插值条件(4.2.6)知, 上式右端实际上等于按 Simpson 公式(4.2.3)求得的积分值 $S$, 因此积分余项
$$R_S = I - S = \int_a^b \left[ f(x) - H(x) \right] \mathrm{d}x.$$
不难证明, 对于满足条件(4.2.6)的多项式 $H(x)$, 其插值余项
$$f(x) - H(x) = \frac{f^{(4)}(\xi)}{4!} (x - a)(x - c)^2 (x - b),$$
故有
$$R_S = \int_a^b \frac{f^{(4)}(\xi)}{4!} (x - a)(x - c)^2 (x - b) \mathrm{d}x.$$
这时积分核 $(x - a)(x - c)^2 (x - b)$ 在 $[a,b]$ 上保号 (非正), 用积分中值定理有
$$R_S = \frac{f^{(4)}(\eta)}{4!} \int_a^b (x - a)(x - c)^2 (x - b) \mathrm{d}x = -\frac{b - a}{180} \left(\frac{b - a}{2}\right)^4 f^{(4)}(\eta).$$
(4.2.7)
关于 Cotes 公式(4.2.4)的积分余项, 这里不再具体推导, 仅列出结果如下:
$$R_C = I - C = -\frac{2(b - a)}{945} \left(\frac{b - a}{4}\right)^6 f^{(6)}(\eta).$$
(4.2.8)
