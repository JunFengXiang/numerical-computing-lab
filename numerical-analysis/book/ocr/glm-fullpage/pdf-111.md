$$\int_{0}^{1} \sqrt{x} f(x) \mathrm{d}x \approx A_{0} f(x_{0}) + A_{1} f(x_{1}),$$
(4.4.7)

令它对于 $f(x) = 1, x, x^{2}, x^{3}$ 准确成立，得

$$\begin{cases} A_{0} + A_{1} = \frac{2}{3}, \\ x_{0} A_{0} + x_{1} A_{1} = \frac{2}{5}, \\ x_{0}^{2} A_{0} + x_{1}^{2} A_{1} = \frac{2}{7}, \\ x_{0}^{3} A_{0} + x_{1}^{3} A_{1} = \frac{2}{9}. \end{cases}$$
(4.4.8)

由于 $x_{0} A_{0} + x_{1} A_{1} = x_{0} \left(A_{0} + A_{1}\right) + \left(x_{1} - x_{0}\right) A_{1}$,

利用式(4.4.8)的第一式，可将第二式化为

$$\frac{2}{3} x_{0} + \left(x_{1} - x_{0}\right) A_{1} = \frac{2}{5}.$$

同样地，利用第二式化第三式，利用第三式化第四式，分别得

$$\frac{2}{5} x_{0} + \left(x_{1} - x_{0}\right) x_{1} A_{1} = \frac{2}{7}, \quad \frac{2}{7} x_{0} + \left(x_{1} - x_{0}\right) x_{1}^{2} A_{1} = \frac{2}{9}.$$

从上面三个式子中消去 $(x_{1} - x_{0}) A_{1}$，有

$$\begin{cases} \frac{2}{5} x_{0} + \left(\frac{2}{5} - \frac{2}{3} x_{0}\right) x_{1} = \frac{2}{7}, \\ \frac{2}{7} x_{0} + \left(\frac{2}{7} - \frac{2}{5} x_{0}\right) x_{1}^{2} = \frac{2}{9}, \end{cases}$$

即

$$\begin{cases} \frac{2}{5} \left(x_{0} + x_{1}\right) - \frac{2}{3} x_{0} x_{1} = \frac{2}{7}, \\ \frac{2}{7} \left(x_{0} + x_{1}\right) - \frac{2}{5} x_{0} x_{1} = \frac{2}{9}. \end{cases}$$

由此解出

$$x_{0} x_{1} = \frac{5}{21}, \quad x_{0} + x_{1} = \frac{10}{9},$$

从而求出

$$x_{0} = 0.821162, \quad x_{1} = 0.289949,$$

$$A_{0} = 0.389111, \quad A_{1} = 0.277556.$$

于是形如式(4.4.7)的 Gauss 公式是

$$\int_{0}^{1} \sqrt{x} f(x) \mathrm{d}x \approx 0.389111 f\left(0.821162\right) + 0.277556 f\left(0.289949\right).$$
