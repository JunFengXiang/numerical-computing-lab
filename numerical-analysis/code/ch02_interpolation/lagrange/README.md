# 两节点线性插值：近似 sin(0.3367)

用教材表值构造线性插值多项式，比较计算值与 `numpy.sin` 的参考值，并画出插值直线和原函数。

## 对应教材

- 公式：[§2.2.2 线性插值与抛物插值](../../../book/verified/sections/2.2.2.md)，式（2.2.4）与（2.2.5）。
- 数据与误差讨论：[§2.2.4 插值余项](../../../book/verified/sections/2.2.4.md)中的例 2.1，原书第 20–21 页 / PDF 第 33–34 页。

| 节点 | 教材表值 | 当前用途 |
| ---: | ---: | --- |
| 0.32 | 0.314567 | 第一个插值节点 |
| 0.34 | 0.333487 | 第二个插值节点 |
| 0.36 | 0.352274 | 保留供二次插值扩展，当前不参与计算 |

所有角度均以弧度计。表值是题目给出的有限精度数据，不是 `sin(x)` 的精确节点值。

## 数学原理

对两个不同节点 $x_0,x_1$，构造

$$
L_1(x)=y_0\frac{x-x_1}{x_0-x_1}
       +y_1\frac{x-x_0}{x_1-x_0}.
$$

它满足 $L_1(x_0)=y_0$、$L_1(x_1)=y_1$。当前目标点 $x=0.3367$ 位于两个节点之间。

## 运行

先按[仓库首页](../../../../README.md#快速开始)建立环境，在仓库根目录执行：

```bash
.venv/bin/python numerical-analysis/code/ch02_interpolation/lagrange/run.py
```

程序会打印输入、结果和误差，并打开图形窗口。无图形界面时可只运行数值部分及非交互绘图：

```bash
MPLBACKEND=Agg .venv/bin/python numerical-analysis/code/ch02_interpolation/lagrange/run.py
```

代码分工：`lagrange.py` 计算插值，`plotting.py` 绘图，`run.py` 定义例题并运行。

## 当前结果

```text
线性插值结果: 0.3303652
sin(x) 参考值: 0.3303741916
绝对误差: 8.9915556281e-06
```

蓝色实线表示 $L_1(x)$，橙色虚线表示 `numpy.sin(x)`，红色点表示参与计算的两个表值节点。在这个很短的区间内，两条曲线视觉上非常接近，应结合数值误差判断。

上面的绝对误差是当前程序相对 `numpy.sin` 参考值的差，包含有限精度表值的影响，不能全部归为使用精确节点函数值时的插值截断误差。教材该例题另有 [NA5E-E002 校注](../../../book/quality/ERRATA.md)，扩展二次插值或引用余项界时需一起阅读。
