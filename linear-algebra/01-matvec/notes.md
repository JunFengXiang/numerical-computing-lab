# 第 1 讲：矩阵与向量相乘

## 核心理解

设 $A\in\mathbb{C}^{m\times n}$，$x\in\mathbb{C}^n$，记 $a_j$ 为 $A$ 的第 $j$ 列。

$$
b_i=\sum_{j=1}^n a_{ij}x_j,
\qquad
Ax=\sum_{j=1}^n x_j a_j.
$$

逐行计算得到各个分量；列视角把整个结果看成各列的线性组合。两者描述同一个矩阵乘法。

- $\operatorname{range}(A)$ 是 $A$ 的列空间。
- $Ax=0$ 表示按 $x$ 给出的系数组合各列后得到零向量。
- 对可逆方阵 $A$，解 $Ax=b$ 得到 $b$ 在 $A$ 的列构成的基下的坐标。

## 与代码对应

| 数学对象或操作 | NumPy 写法 |
| --- | --- |
| $Ax$ | `A @ x` |
| 第 $j$ 列 | `A[:, j]`，代码下标从 0 开始 |
| 行变换 | 在左侧乘初等矩阵 |
| 列变换 | 在右侧乘初等矩阵 |

实验中的 `x.shape == (n,)` 是 NumPy 的一维数组表示；数学上仍把它理解为列向量。
