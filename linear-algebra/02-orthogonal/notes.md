## 核心理解

复向量内积为 $x^*y=\sum_i\overline{x_i}y_i$。它对第一个变量共轭线性，对第二个变量线性；在实数域上才是双线性。

若 $Q=[q_1,\ldots,q_k]$ 的列标准正交，即 $Q^*Q=I$，则

$$
p=QQ^*v,\qquad r=v-p,\qquad Q^*r=0.
$$

$p$ 是 $v$ 在这些列张成的子空间上的正交投影；$r$ 是与该子空间正交的剩余部分。

若 $Q$ 为方阵且酉，则 $Q^*=Q^{-1}$，乘以 $Q$ 保持 2-范数。对于一般的瘦矩阵 $Q$，不能把 $Q^*Q=I$ 与 $QQ^*=I$ 混为一谈。

## 与代码对应

| 数学对象 | NumPy 写法 |
| --- | --- |
| $A^*$ | `A.conj().T` |
| 一维向量的 $x^*y$ | `np.vdot(x, y)` |
| $QQ^*v$ | `Q @ (Q.conj().T @ v)` |
| $\|r\|_2$ | `np.linalg.norm(r)` |

浮点实验中的“为零”通常表现为一个很小的数。判断时结合问题尺度使用容差。
