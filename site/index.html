Matrix × Vector · 行视角 / 列视角 · Interactive Lab V0.1

矩阵乘向量，不只是“按公式算”

固定矩阵 F，改变系数向量 c。观察同一个乘法 Fc=d 如何从两种互补视角理解：列视角强调“列向量的线性组合”，行视角强调“每一行与 c 做内积”。

\[Fc=d\]

列视角：组合列，而不是“cF”

若 F=[f₁ f₂ f₃]，则

\[Fc=c_1f_1+c_2f_2+c_3f_3=d.\]

系数来自右侧向量 c；因此是矩阵 F 的各列按 c 的分量做线性组合。

行视角：逐行做内积

若 F 的三行为 r₁ᵀ,r₂ᵀ,r₃ᵀ，则

\[d_i=r_i^Tc.\]

每个输出分量 dᵢ 都由 F 的第 i 行与 c 的内积产生。
